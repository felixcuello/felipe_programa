# Unidad 2: Algoritmos - Ejercicios de Práctica

## Módulos 2 y 3: Estructuras Secuenciales, de Decisión y de Repetición

## Sección A: Tipos de Datos y Variables (Problemas 1-25)

### Problema 1
Define las variables necesarias (con su tipo de dato) para almacenar: el nombre de una persona, su edad, su estatura y si está casada o no.

### Problema 2

### Problema 3

### Problema 4

### Problema 5
¿Cuál es la diferencia entre usar un tipo entero y un tipo flotante para almacenar la edad de una persona? ¿Cuál es más apropiado?

### Problema 6
Define las variables para representar una cuenta bancaria: número de cuenta, titular, saldo, tipo de cuenta, fecha de apertura.

### Problema 7

### Problema 8
Define las variables necesarias para un sistema de calificaciones: nombre del estudiante, matrícula, calificación parcial 1, 2 y 3, asistencia.

### Problema 9
¿Qué sucede si intentas guardar el valor 3.5 en una variable de tipo entero?

### Problema 10
Define las variables para representar un vuelo: número de vuelo, origen, destino, hora de salida, capacidad, asientos disponibles.

### Problema 11
Identifica el tipo de dato para: número de teléfono, latitud geográfica, nombre de usuario, contraseña válida, intentos de login.

### Problema 12
Define las variables necesarias para un pedido en línea: ID del pedido, cliente, productos, total, pagado, fecha de entrega.

### Problema 13
¿Por qué el número de teléfono debería almacenarse como cadena y no como entero?

### Problema 14

### Problema 15

### Problema 16
Define las variables para un empleado: nombre, puesto, salario mensual, fecha de ingreso, tiene seguro, departamento.

### Problema 17
¿Qué tipos de datos necesitas para representar una fecha completa (día, mes, año)?

### Problema 18

### Problema 19

### Problema 20

### Problema 21

### Problema 22

### Problema 23

## Notas para el Estudiante

- Practica escribiendo algoritmos en pseudocódigo antes de codificar.
- Identifica claramente qué tipo de estructura necesitas: secuencial, selección o repetición.
- Las estructuras pueden combinarse y anidarse según la complejidad del problema.
- Verifica tus algoritmos con diferentes casos de prueba.
- Recuerda: primero piensa en la lógica, luego en la sintaxis.
